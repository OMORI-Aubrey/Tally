# 01. 개요

Tally가 **지금 실제로 어떻게 동작하는지**를 코드 기준으로 적은 문서 모음이다. 기획서·와이어프레임(원안)과 구현이 다른 곳은 [09-changes](09-changes.md)에 모았다.

## Tally는

공부 세션 동안 스마트폰을 언제 어떤 앱으로 열었는지를 OS 사용 기록에서 되살려, 세션이 **몇 조각으로 끊겼는지**와 **가장 길게 안 끊고 이어간 시간**을 보여 주는 Android 앱이다.

1. 타이머로 세션을 시작한다(과목은 선택). 세션 중에는 앱이 아무것도 하지 않는다 — 차단도, 알림도, 백그라운드 감시도 없다.
2. 종료하면 세션 동안의 사용 기록을 한 번 조회해 타임라인을 복원하고 지표를 계산해 저장한다.
3. 주 1회, 실측을 보여 주기 전에 체감 집중 시간을 묻는다.
4. 세션 리포트에 최장 구간·조각 수·타임라인 스트립·순공·딴짓 순간을 보여 준다.

서버·네트워크 권한·분석 SDK가 없고 기록은 기기 밖으로 나가지 않는다.

**구현 범위** — P0~P5(안전선)까지 완료. 기준선·주간 판정·다음 목표·기록 탭 판정/이번 주/누적 섹션(P6·P7)은 아직 없다. 진행 상황은 [README](../../README.md#진행-상황)와 [PLAN.md](../../PLAN.md).

## 용어

| 용어 | 뜻 | 코드 |
|---|---|---|
| 세션 | 타이머 시작부터 종료까지 | `StudySession` |
| 과목 | 세션에 붙이는 라벨 문자열. 선택 사항이고 지표 계산에 쓰지 않는다 | `subjectName` |
| 구간 | 복원한 타임라인의 한 토막 `[시작, 끝)` | `AppSegment`, `Segment` |
| 허용 / 딴짓 | 앱 분류 두 가지. 딴짓 구간은 순공에서 빠지고 연속을 끊는다 | `ALLOWED` / `DISTRACT` |
| 화면 꺼짐 | 폰을 만지지 않은 구간. 순공에 들어간다 | `SCREEN_OFF`, `__SCREEN_OFF__` |
| 화면 켜짐 (앱 없음) | 화면만 켜고 앱은 열지 않은 구간(잠금화면·알림창). 딴짓이다 | `__SCREEN_ON_UNKNOWN__` |
| 자리 비움 | 60분 넘게 꺼진 화면 구간을 사용자가 `[자리 비웠어요]`로 고른 것. 공부 시간·순공 어디에도 들지 않는다 | `AWAY` |
| 공부 (착석) | 세션 길이 − 자리 비움. 기획서의 "착석"을 화면에서는 "공부"로 쓴다 | `T_total`, `tTotalSec` |
| 순공 최대 | 공부 − 딴짓. 폰 밖의 딴짓은 잴 수 없어 상한 추정이라 늘 "최대"를 붙인다 | `T_focus`, `tFocusSec` |
| 최장 구간 | 딴짓·자리 비움 없이 이어간 가장 긴 시간. 앱의 대표 지표 | `LFS`, `lfsSec` |
| 이탈 / 조각 | 딴짓 구간의 개수 / 이탈 + 1. `6조각` | `N_int`, `interruptionCount` |
| 집중 밀도 | 순공 ÷ 공부 × 100 | `D`, `densityPct` |
| 체감 | 사용자가 적은 "집중한 것 같은 시간"(분). 주 1회 묻는다 | `perceivedFocusMin` |
| 인식 격차 | (체감 − 순공) ÷ 순공 × 100. 양수가 과대평가 | `G` |
| 타임라인 있음 | 사용 기록 권한이 있어 구간을 복원한 세션. 없으면 공부 시간만 남는다 | `hasTimeline` |
| 통계 포함 | 공부 3분 이상·180분 이하(180분 초과는 답에 따라)이고 불변식이 깨지지 않은 세션 | `isValidForStats` |
| 통계에 셀 세션 | 통계 포함 + 타임라인 있음. 주간 요약 줄·체감 질문·리포트의 기록이 이것만 센다 | `countsInStats` |
| 자동 분류 / 사용자 분류 | 규칙으로 정한 분류 / 사용자가 정한 분류. 사용자 분류는 자동 분류가 덮지 않는다 | `AUTO_CATEGORY` / `USER` |
| 불변식 | 구간들이 세션 전체를 빈틈·겹침 없이 덮는다 | `checkInvariant` |
| 기준선 (P6) | 이번 주를 뺀 직전 4주의 개인 평균. 판정·목표의 기준. 아직 없다 | — |
| 주 | 월요일 00:00(기기 시간대)부터 7일 | `weekRangeOf` |
