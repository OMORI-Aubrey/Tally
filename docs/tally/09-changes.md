# 09. 기획서·와이어프레임과 달라진 점

P0~P7을 구현하면서 원안 문서와 다르게 정했거나, 원안이 정하지 않아 새로 정한 것이다. 원안은 그대로 두었다([`docs/Tally-MVP-Proposal.md`](../Tally-MVP-Proposal.md) = 기획서 `§n`, [`docs/Tally-wireframe.md`](../Tally-wireframe.md) = 와이어프레임 `WF §n`).

- **근거**의 "PLAN §4 「…」"는 [PLAN.md §4 착수 전 확정할 결정](../../PLAN.md#4-착수-전-확정할-결정) 표의 그 줄이다. 이유는 거기에 있어 여기서는 되풀이하지 않는다. "PLAN #N"은 PLAN.md 단계별 작업의 그 이슈 설명이다.

## 원안에 이미 반영된 것

P0에서 정한 아래 결정은 기획서 본문에 이미 들어 있다. 원안과 구현이 같다.

- 입력 이벤트에 `KEYGUARD_HIDDEN` 추가, 잠금 해제 규칙, 흡수 임계값 5초/`__SCREEN_ON_UNKNOWN__` 10초(§6.1·§6.2·§6.2.1 — #3에서 반영)
- `Category.AWAY`, `StudySession.hasTimeline`, `StudySession.metricsVersion`, enum을 Room TEXT로 저장(§9)
- 최소 SDK 29(§10.1)
