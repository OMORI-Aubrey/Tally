# 07. 화면

지금 앱에 있는 화면과 실제 문구다. 문구는 모두 [`strings.xml`](../../app/src/main/res/values/strings.xml)에 있다. 화면 코드는 [`ui/screens/`](../../app/src/main/java/com/jaeyun/tally/ui/screens), 공용 부품은 [`ui/components/`](../../app/src/main/java/com/jaeyun/tally/ui/components)([08-design](08-design.md#컴포넌트)).

## 화면 구성

라우트 7개([`Routes.kt`](../../app/src/main/java/com/jaeyun/tally/ui/Routes.kt))와 하단 탭 3개(타이머·기록·설정).

| 라우트 | 화면 | 하단 탭 |
|---|---|---|
| `Onboarding` | 온보딩 (처음 한 번) | 없음 |
| `Timer` | 타이머 (IDLE / RUNNING) | 있음. RUNNING에서는 탭만 아래로 내려 숨긴다 |
| `Records` | 기록 탭 | 있음 |
| `Settings` | 설정 탭 | 있음 |
| `AppClassification` | 설정 → 앱 분류 | 없음 |
| `PerceivedInput(sessionId)` | 체감 입력 | 없음 |
| `SessionReport(sessionId)` | 세션 리포트 | 없음 |

과목 선택은 타이머의 바텀시트이고, 세션 진행(RUNNING)은 타이머의 상태라 라우트가 아니다. 다이얼로그는 타이머 화면 위에 뜬다.

```
[처음 한 번] 온보딩
      ↓
 타이머 ──── 기록 ──── 설정
   │  └→ 과목 시트   │      └→ 앱 분류
   │ 종료           │
   ↓               │
 ① ② 다이얼로그      │
   ↓               │
 체감 입력 (주 1회)   │
   ↓               │
 세션 리포트 ◀───────┘ (세션 목록에서)
```

이동 규칙([`TallyApp.kt`](../../app/src/main/java/com/jaeyun/tally/ui/TallyApp.kt)) — [02-architecture](02-architecture.md#내비게이션)에 자세히.

## 온보딩

[`OnboardingScreen`](../../app/src/main/java/com/jaeyun/tally/ui/screens/onboarding/OnboardingScreen.kt) · 한 화면. 위쪽은 스크롤되고, 권한 안내와 버튼은 화면 아래에 고정이라 `[권한 설정하기]`가 첫 화면에서 늘 보인다. 과목은 받지 않는다.

위쪽(스크롤)

1. 로고
2. 헤드라인 `3시간 공부했다고 생각한 날 / 실제로 안 끊고 이어간 건` **`11분`** `일 수 있습니다` — `11분`을 가장 크게, 파란 볼펜으로
3. `하루 평균 몇 시간 정도 공부하세요? (선택)` + 슬라이더 1~12시간, 1시간 단위. 고른 값은 오른쪽에 `3시간`처럼 파란 볼펜으로 쓴다. **처음에는 손잡이 없이 눈금만 있고**, 건드리지 않고 넘어가면 건너뛴 것이다. 화면 낭독기는 `하루 평균 공부 시간`, 고르기 전에는 `고르지 않음`으로 읽는다
4. `ⓘ` 안내 세 줄
   - `과목이 바뀌면 세션을 끊어주세요. 조각이 정확해집니다`
   - `공부하는 동안 어떤 앱을 언제 열었는지, 화면을 언제 켜고 껐는지만 읽어요. 안 끊고 이어간 시간을 찾는 데만 써요`
   - `앱 안의 내용, 화면 내용, 위치, 연락처는 읽지 않아요. 기록은 이 기기에만 저장됩니다`

아래(고정) — 권한 상태에 따라 바뀐다.

| 상태 | 보이는 것 |
|---|---|
| 꺼져 있음 | 포스트잇 `[권한 설정하기]를 누르면 시스템 설정이 열립니다` / `1 목록에서 "Tally"를 찾아 탭하세요` / `2 스위치를 켜고 뒤로 돌아오세요` + `[권한 설정하기]` + `나중에 하기` |
| 설정에 다녀왔는데 아직 꺼져 있음 | 포스트잇 첫 줄만 `아직 꺼져 있어요. 아래 순서대로 켜 주세요` |
| 처음부터 켜져 있음 | `사용 기록 접근이 켜져 있어요` + `[시작하기]` |

- `[권한 설정하기]`는 사용 기록 접근 설정을 연다. 앱을 지정해 열 수 없어 설치된 앱 전체 목록이 열린다.
- 화면이 다시 보일 때마다 권한을 확인한다. **`[권한 설정하기]`로 다녀와 켰으면 버튼을 한 번 더 누르지 않고 바로 타이머로 간다.**
- `나중에 하기`·`시작하기`·권한 켜고 돌아옴 → 자기보고 값(시간 × 60분, 건너뛰면 지움)과 온보딩 완료를 저장하고 타이머로 간다. 온보딩은 백스택에서 지워져 타이머에서 뒤로가면 앱을 나간다.
- 고른 시간과 `[권한 설정하기]`를 누른 적이 있는지는 `SavedStateHandle`에 둔다. 설정에 가 있는 동안 앱 프로세스가 정리돼도 돌아와서 이어진다.

## 타이머

[`TimerScreen`](../../app/src/main/java/com/jaeyun/tally/ui/screens/timer/TimerScreen.kt), [`TimerViewModel`](../../app/src/main/java/com/jaeyun/tally/ui/screens/timer/TimerViewModel.kt). 상태는 Room의 진행 중 세션(`endAt = null`) 하나로 정한다. 확인하기 전에는 빈 화면(Loading)이라 IDLE이 잠깐 보였다가 RUNNING으로 바뀌는 깜빡임이 없다.

### IDLE (시작 전)

위에서부터

1. 로고
2. 주간 요약 줄 `이번 주 최장 47분 · 평균 28분` + 연필 화살표. 숫자만 파란 볼펜. 누르면 기록 탭으로 간다. 셀 세션이 없으면 `첫 세션을 시작해보세요`(누를 수 없음) — 숫자 규칙은 [05-metrics](05-metrics.md#주간-요약-줄의-숫자)
3. `과목 선택` + 과목 칩
4. 원형 `[시작]` 버튼(손그림)
5. 그 아래 한 줄: 칩이 있으면 `과목이 바뀌면 끊어주세요`, 칩이 없으면 `과목 없이도 시작할 수 있어요`

`[시작]`을 누르면 고른 과목(없으면 과목 없이)으로 세션 행을 바로 저장한다.

### 과목 칩과 과목 시트

과목은 선택 사항이다. 과목은 세션의 라벨 문자열이라 별도 테이블이 없다([03-data](03-data.md#datastore-키)).

**칩** ([`SubjectChipRow`](../../app/src/main/java/com/jaeyun/tally/ui/components/timer/SubjectChipRow.kt))

- 마스킹테이프 모양. 칩마다 조금씩 기울고, 고른 칩은 형광펜 색. 한 줄을 넘으면 다음 줄로.
- 최근에 쓰거나 추가한 순서로 **5개까지**, 칩에서 숨긴 과목은 빠진다. 시트에서 고른 과목이 5개 밖이면 맨 앞에 넣는다.
- 앱을 열면 마지막 세션의 과목을 골라 둔다(숨긴 과목이었거나 과목 없이 시작했으면 고르지 않음).
- 누르면 고르고, 고른 칩을 다시 누르면 선택을 푼다(과목 없이 시작). 길게 누르면 `이름 바꾸기`·`칩에서 숨기기` 메뉴.
- 끝에 `+` 칩. 과목이 하나도 없으면 `+ 과목 추가 (선택)`. 누르면 과목 시트가 열린다.

**과목 시트** ([`SubjectSheet`](../../app/src/main/java/com/jaeyun/tally/ui/screens/timer/SubjectSheet.kt)) — 바텀시트, 내용 높이는 화면의 60%까지(목록만 스크롤)

- 제목 `과목 선택`. 목록은 **세션 많은 순**(같으면 최근 순). 숨긴 과목도 이름을 흐리게 하고 빗금 친 눈 아이콘을 붙여 보인다(화면 낭독기는 `칩에서 숨김`).
- 한 줄: 과목 이름 · `N세션`(세션이 없는 과목은 생략) · ⋮(`이름 바꾸기`, `칩에서 숨기기` / `다시 표시`). **삭제는 없다.**
- 줄을 누르면 그 과목을 고르고 닫힌다.
- 아래 입력창 `새 과목 입력` + `추가`. 앞뒤 공백을 지우고 연속 공백을 하나로 줄이며 20자까지. 이미 있는 이름이면 그 과목을 고르고, 숨긴 과목이면 다시 보이게 한다. 추가하면 고르고 시트를 닫는다.
- 과목이 없으면 `아직 추가한 과목이 없어요` / `과목을 나누면 나중에 기록을 찾기 쉬워져요`.

**이름 바꾸기** ([`RenameSubjectDialog`](../../app/src/main/java/com/jaeyun/tally/ui/screens/timer/RenameSubjectDialog.kt)) — 칩 길게 누르기와 시트 ⋮ 양쪽에서 연다.

- 제목 `과목 이름 바꾸기`, `[바꾸기]`·`[취소]`. 이름이 바뀌어야 `[바꾸기]`가 눌린다.
- 과거 세션까지 바뀐다. 세션이 있는 과목이면 `"수햑"을 "수학"으로 바꾸면 기존 세션 N개도 함께 바뀌어요`.
- 이미 있는 과목 이름이면 `이미 있는 "수학" 과목의 세션 N개와 합쳐져요` — 두 과목이 하나가 된다.

### RUNNING (진행 중)

- 과목 이름(형광펜) — 과목 없이 시작했으면 빈 줄
- 경과 시간 `01:11:18` — `HH:MM:SS`, 파란 볼펜, 자릿수 폭 고정. 화면이 보일 때만 초가 바뀌는 순간에 맞춰 다시 그린다
- `[종료]` 버튼(손그림 사각형)

그 밖에는 아무것도 없다. 하단 탭은 아래로 내려 숨기되 자리는 남겨 `[종료]`가 움직이지 않는다. `[시작]`을 눌러 들어올 때만 `[종료]`가 위에서 내려오고 경과 시간이 왼쪽 글자부터 나타난다. 앱을 다시 열어 이어질 때는 애니메이션이 없다.

경과 시간은 저장하지 않고 `지금 − 시작 시각`으로 그린다. 앱을 강제 종료해도 다시 열면 그대로 이어진다.

## 다이얼로그

[`TimerDialogs.kt`](../../app/src/main/java/com/jaeyun/tally/ui/screens/timer/TimerDialogs.kt), 공용 [`TallyDialog`](../../app/src/main/java/com/jaeyun/tally/ui/components/feedback/TallyDialog.kt). 종이 바탕에 질문, 설명 한 줄, 손그림 버튼을 위에서부터 둔다. **뒤로가기·바깥 누르기로 닫히지 않는다.** 첫 버튼이 기록을 그대로 두는 쪽, 두 번째가 바꾸는 쪽이다. 한 번에 하나만 뜬다.

| | 뜨는 때 | 질문 / 설명 | 버튼 |
|---|---|---|---|
| ① | 종료 후, 화면 꺼짐 단일 구간이 60분을 넘을 때 구간마다(시각순) | `23:14~00:51 동안 화면이 꺼져 있었어요. 이 시간은 어떻게 할까요?` / `자리 비움으로 하면 공부 시간에서 빠져요` | `[공부했어요]` `[자리 비웠어요]` |
| ② | ① 다음, 자리 비움을 뺀 공부 시간이 180분을 넘을 때 | `공부 시간이 3시간 12분이에요. 종료를 잊으셨나요?` / `종료를 잊었으면 기록만 남기고 통계에서 빼요` | `[계속 공부했어요]` `[종료를 잊었어요]` |
| ③ | 앱을 열 때, 세션을 시작한 뒤 재부팅했으면(같은 재부팅은 한 번만) | `휴대폰을 다시 켜기 전에 시작한 세션이 있어요. 이어서 기록할까요?` / `코틀린 · 9/7 19:00 시작`(과목이 없으면 `9/7 19:00 시작`) | `[이어서 기록]` `[삭제]` |

강제 종료나 최근 앱에서 지운 경우는 ③을 묻지 않고 그대로 이어진다. 동작은 [04-timeline](04-timeline.md#예외-처리-6건-63).

## 체감 입력

[`PerceivedInputScreen`](../../app/src/main/java/com/jaeyun/tally/ui/screens/perceived/PerceivedInputScreen.kt) · 주 1회만, 리포트 **전에** 뜬다(규칙은 [05-metrics](05-metrics.md#체감-질문-주-1회)). 실측값은 어디에도 보이지 않는다.

- `방금 세션에서` / `몇 분 정도 집중한 것 같나요?`
- 빈칸 + 숫자 키패드. 세션이 1시간 이상이면 `_ 시간 __ 분`(시간 칸에 세션 길이 안의 숫자를 적으면 분 칸으로 넘어간다), 1시간 미만이면 `__ 분`. 미리 채운 숫자가 없다.
- 넘치면 `2시간 30분까지 적을 수 있어요`, 분 칸이 60 이상이면 `분은 59까지 적을 수 있어요`. 바른 값일 때만 `[확인]`이 눌린다.
- `건너뛰기`와 뒤로가기는 답 없이 리포트로 간다. 그 주에는 다시 묻지 않는다.
- 답하면 리포트로 바뀐다(체감 입력은 백스택에서 빠져 리포트에서 뒤로가면 타이머로 온다). 리포트를 먼저 보고 돌아와 답하는 길은 없다.

## 세션 리포트

[`SessionReportScreen`](../../app/src/main/java/com/jaeyun/tally/ui/screens/report/SessionReportScreen.kt), 내용 계산은 [`SessionReport.kt`](../../app/src/main/java/com/jaeyun/tally/ui/screens/report/SessionReport.kt). 세션 종료 직후와 기록 탭 세션 목록에서 연다. 위 막대는 `세션 리포트` + `닫기`(뒤로가기와 같다). 판정·목표는 없다(주 단위라 기록 탭 몫).

위에서부터

| | 자리 | 내용 | 없을 때 |
|---|---|---|---|
| ⓪ | 격차 포스트잇 | `체감 2시간` / `실측 최대 1시간 28분` / `+36% 과대평가`(빨간 펜 동그라미) · `-12% 과소평가`(파란 볼펜) · `체감과 실측이 같아요` / `가장 길게 이어간 건` **`34분`** | 체감을 적지 않았거나, 타임라인이 없거나, 순공이 0초 |
| ① | 구조 헤드라인 | `최장 34분` · `끊긴 결과 6조각`(이탈 0회면 `이 세션에는 이탈이 없었어요`) / `세션 1시간 38분 중 34%` / `기록 47분` 또는 `기록 갱신` | 타임라인 없음 |
| ② | 흐름(스트립) | 소제목 `흐름`, 세션 전체를 한 막대에 구간 길이 그대로. 아래에 시작·종료 시각과 나온 종류만 범례 | 타임라인 없음 → 권한 유도 배너. 구간이 세션을 빈틈 없이 덮지 않으면 그리지 않는다 |
| ③ | 총량 | `순공 최대 1시간 28분`(형광펜) / `공부 1시간 38분 · 딴짓 10분` | 타임라인 없으면 `공부 …`만, 딴짓 0이면 `· 딴짓` 생략 |
| ④ | 지표 카드 | `집중 밀도 87%`, `세션 길이 1시간 38분`(색인 카드) | 타임라인 없음. 밀도 0%면 밀도 카드만 없음 |
| ⑤ | 딴짓한 순간 | 소제목 + `길게 눌러 고치기`. 한 줄 `19:24 ● 인스타그램 ······ 3분`, 화면만 켠 구간은 `화면 켜짐 (앱 없음)` | 이탈 없음·타임라인 없음 |
| ⑥ | 미분류 앱 질문 | `"카카오톡"은 어떤 앱인가요?` `[딴짓]` `[허용]` 최대 2개, 답한 뒤 결과 한 줄 | 물을 앱 없음 |
| ⑦ | 메타 | `코틀린 · 9/7 19:00~20:38`(과목 없으면 생략) + 통계 제외면 `통계에 넣지 않는 세션이에요` | — |

- 숫자 규칙: ① `기록`은 이 세션이 통계에 셀 세션이고 견줄 다른 세션이 있을 때만, 이 세션이 더 길면 `기록 갱신`. ④ 세션 길이는 타이머 길이(종료 − 시작)다. 공부 시간(착석)은 자리 비움이 빠지므로 다를 수 있다.
- 스트립 색: 허용 앱·화면 꺼짐·딴짓·화면 켜짐·자리 비움 5종([08-design](08-design.md#색)). 딴짓·화면 켜짐은 위아래를 꽉 채우고 나머지는 조금 얇게 그려 짧은 딴짓도 튀어나와 보인다. 높이 40dp. 폭 비율은 고치지 않는다.
- ⑤ 앱 줄을 누르거나 길게 누르면 `허용 앱으로 바꾸기` 메뉴. ⑤⑥에서 분류를 정하면 그 세션을 다시 계산한다([06-classification](06-classification.md#리포트-안-재분류)).

**사용 기록 권한 없이 끝낸 세션** — ①④⑤⑥이 없고 ② 자리에 권한 유도 배너를 둔다.

- `이 세션은 사용 기록 없이 공부 시간만 남았어요`
- 지금 꺼져 있으면: `사용 기록 접근을 켜면 다음 세션부터 끊긴 구간과 딴짓한 순간이 보여요` + 온보딩과 같은 순서 포스트잇 + `[권한 설정하기]`
- 지금 켜져 있으면: `지금은 켜져 있어요. 다음 세션부터 끊긴 구간과 딴짓한 순간이 보여요`
- 화면이 보일 때마다 권한을 다시 확인한다. 켜도 이 세션은 다시 계산하지 않는다.

세션을 찾을 수 없으면 `세션을 찾을 수 없어요`.

## 기록 탭

[`RecordsScreen`](../../app/src/main/java/com/jaeyun/tally/ui/screens/records/RecordsScreen.kt) · **지금은 날짜별 세션 목록만 있다.** 판정·이번 주·누적 섹션은 P6·P7에서 목록 위에 붙는다.

- 머리말 `세션 목록` ··· `공부`(오른쪽 값의 이름을 한 번만)
- 날짜 머리말: `오늘`, `어제`, 그 밖에는 `9월 28일 (월)`. 세션은 **시작 시각**의 날짜에 들어간다(자정을 넘겨도 시작한 날).
- 한 줄 `19:00  수학 ········ 1시간 38분` — 시작 시각, 과목(없으면 비워 둔다), 공부 시간(착석). 최근 순.
- 통계에서 빠진 세션(3분 미만·180분 초과·불변식 위반)은 글자를 가장 흐린 연필색으로 쓰고 시각·과목·값에 연필 가운뎃줄을 따로 긋는다. 화면 낭독기는 `통계 제외`로 읽는다.
- 줄을 누르면 그 세션의 리포트가 열린다.
- 끝난 세션이 하나도 없으면 `세션을 마치면 여기에 기록이 쌓입니다` 한 줄만.

## 설정 탭

[`SettingsScreen`](../../app/src/main/java/com/jaeyun/tally/ui/screens/settings/SettingsScreen.kt) · 줄은 모두 [`SettingsRow`](../../app/src/main/java/com/jaeyun/tally/ui/components/settings/SettingsRow.kt).

| 줄 | 설명·상태 | 누르면 |
|---|---|---|
| `앱 분류` › | `감지된 앱을 딴짓·허용으로 바꿔요` | 앱 분류 화면 |
| `사용 정보 접근 권한` › | `켜져 있어요` / `꺼져 있어요`. 화면이 보일 때마다 다시 확인 | 켜져 있든 꺼져 있든 시스템 설정(켜거나 끄러 간다) |
| `데이터 전체 삭제` (빨간 펜) | — | 확인 다이얼로그 |

**데이터 전체 삭제** — `모든 데이터를 지울까요?` / `세션 기록과 앱 분류, 설정이 모두 지워지고 되돌릴 수 없어요` / `[그대로 두기]` `[모두 지우기]`. 뒤로가기·바깥 누르기로 닫히지 않는다. `[모두 지우기]`면 Room 전체·DataStore 전체·내보낸 CSV를 지우고 **바로 온보딩으로 간다**(하단 탭 없음). 백스택과 탭마다 보존한 백스택을 모두 비워, 지워진 세션의 리포트가 되살아나지 않는다. 사용 기록 접근 권한은 남는다.

**개발자 영역** (debug 빌드에서만, 소제목 `개발자`)

| 줄 | 설명 | 누르면 |
|---|---|---|
| `CSV 내보내기` | `끝난 세션을 한 줄씩 CSV로 공유해요` | CSV를 만들어 공유 시트(`CSV 공유`)를 연다 |
| `데모 데이터 주입` | 세션이 없으면 `지난 5주의 합성 세션을 넣어요. 발표 리허설용이에요`, 있으면 `기록이 있으면 넣지 않아요. CSV로 내보내고 전체 삭제한 뒤 넣을 수 있어요`(흐리게, 누를 수 없음), 넣은 뒤 `데모 데이터를 넣었어요. 지우려면 데이터 전체 삭제` | 데모 데이터를 넣는다 |
| `기준선 조건 완화` | `켜짐 · 유효 세션 6개부터 기준선을 계산해요` / `꺼짐 · 유효 세션 12개부터 기준선을 계산해요` | 켜짐·꺼짐을 바꾼다(값만 저장, 기준선 계산은 P6 #24) |

삭제·내보내기·데모 주입은 연타해도 한 번만 한다. 자세한 내용은 [10-development](10-development.md#개발자-영역).

## 앱 분류

[`AppClassificationScreen`](../../app/src/main/java/com/jaeyun/tally/ui/screens/appclass/AppClassificationScreen.kt) · 위 막대 `앱 분류` + `뒤로`.

- `공부 중 감지된 앱만 보여요. 바꾸면 다음 세션부터 반영돼요`
- 한 줄 `● 유튜브 ········ 딴짓 | 허용` — 점 색은 딴짓·허용 구간 색. 고른 쪽을 형광펜으로 칠한다(스위치 대신 둘 중 하나를 고른다).
- 이름 순서(한국어 가나다). 바꿔도 줄이 움직이지 않는다.
- 맨 아래 `브라우저는 강의 시청과 딴짓을 구분할 수 없어 기본값이 딴짓이에요`
- 감지된 앱이 없으면 `아직 감지된 앱이 없어요. 세션을 마치면 공부 중에 연 앱이 여기에 나와요`

규칙은 [06-classification](06-classification.md).
