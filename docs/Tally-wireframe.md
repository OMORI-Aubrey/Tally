# Tally 화면 구성 설계

디자인 참고용. 기획서 §8 기준. 치수·색상·서체는 지정하지 않고 **배치와 위계**만 담는다.

---

## 0. 전역 원칙

디자인할 때 계속 적용되는 규칙 다섯 개.

| # | 원칙 |
|---|---|
| 1 | **첫 숫자는 "몇 조각"이지 "몇 시간"이 아니다.** 최장 구간과 이탈 횟수를 가장 크게, 순공·착석은 그 아래 |
| 2 | **0을 표시하지 않는다.** "0회", "0분", "0%" 대신 문장으로 대체 |
| 3 | **숫자 자리를 빈칸으로 두지 않는다.** `최장 --분`은 고장으로 보인다 |
| 4 | **판정과 목표는 기록 탭 안에만 있다.** 타이머 화면에 절대 노출 금지 |
| 5 | **순공시간에는 항상 "최대"를 붙인다.** `최대 1시간 28분` |
| 6 | **선택 사항의 부재를 결함처럼 보이게 하지 않는다.** 과목이 없으면 자리를 생략한다. `(과목 없음)` 금지. 대신 행동을 유도할 때는 `(선택)`을 문구에 명시 |

### 타이포 위계 (3단)

```
L1   최장 구간, 이탈 횟수, 경과 시간, 판정 문구      가장 큼
L2   순공 · 착석 · 딴짓, 집중 밀도                  중간
L3   메타, 근거, 라벨, 목록                        작음
```

### 색 역할 (3색 + 중립)

```
DISTRACT              딴짓          경고색
ALLOWED               허용 앱       중립/차분
SCREEN_OFF            화면 꺼짐     가장 연함
__SCREEN_ON_UNKNOWN__ 화면 켜짐     DISTRACT와 같은 계열, 약하게
```

타임라인 스트립과 이탈 목록에서 같은 색 규칙을 쓴다.

## 1. 온보딩 — 1화면

```
┌──────────────────────────────┐
│                              │
│   [일러스트 또는 여백]        │
│                              │
│   3시간 공부했다고 생각한 날   │  ← L1
│   실제로 안 끊고 이어간 건     │
│   11분일 수 있습니다          │
│                              │
│   ─────────────────────      │
│   하루 평균 몇 시간 정도       │  ← L3 라벨
│   공부하세요?                 │
│                              │
│   ○──────●──────○   3시간     │  ← 슬라이더 1개
│                              │
│   ─────────────────────      │
│   ⓘ 과목이 바뀌면 세션을      │  ← L3, 작게
│     끊어주세요. 조각이         │
│     정확해집니다              │
│                              │
│   ⓘ 기록은 이 기기에만        │
│     저장됩니다                │
│                              │
│   [권한 설정하기]를 누르면     │
│   시스템 설정이 열립니다       │
│    1. 목록에서 "Tally" 찾기   │  ← 번호 목록 필수
│    2. 스위치 켜고 뒤로가기     │
│                              │
│   ┌────────────────────┐     │
│   │   권한 설정하기     │     │  ← 주 버튼
│   └────────────────────┘     │
│        나중에 하기            │  ← 텍스트 버튼
└──────────────────────────────┘
```

**디자인 주의점**

- 스크롤이 생겨도 된다. 다만 `[권한 설정하기]`가 첫 화면에서 보여야 한다
- **번호 목록(1·2)을 시각적으로 강조한다.** 여기서 이탈이 가장 많이 발생한다. 시스템 설정은 전체 앱 목록이 열리므로 안내가 유일한 방어선
- 슬라이더는 건너뛸 수 있게 한다 (건너뛰면 1주차 격차 리포트만 미표시)
- 헤드라인의 "11분"이 이 앱의 첫인상이다. 가장 크게

## 2. 타이머 탭 — 홈

### 2-A. IDLE (시작 전)

```
┌──────────────────────────────┐
│                              │
│  이번 주 최장 47분 · 평균 28분 ›│  ← L3, 탭 가능. 기록 탭으로
│                              │
│                              │
│         [ 과목 선택 ]          │
│   ┌────┐┌────┐┌────┐┌────┐  │
│   │수학││영어││국어││ + │    │  ← 최근 5개 / +는 시트
│   └────┘└────┘└────┘└────┘  │
│                              │
│                              │
│        ┌──────────┐          │
│        │          │          │
│        │   시작   │          │  ← 가장 큰 터치 타깃
│        │          │          │
│        └──────────┘          │
│                              │
│   과목이 바뀌면 끊어주세요      │  ← L3, 매우 작게
│                              │
├──────────────────────────────┤
│   ⏱ 타이머   📊 기록   ⚙ 설정  │
└──────────────────────────────┘
```

**빈 상태 ① 이번 주 세션 0개** — 요약 줄을 `첫 세션을 시작해보세요`로 대체. 숫자 자리를 비우지 않는다.

**빈 상태 ② 과목 0개 (첫 실행 직후)**

```
┌──────────────────────────────┐
│                              │
│  첫 세션을 시작해보세요        │
│                              │
│                              │
│   ┌────────────────────┐     │
│   │ + 과목 추가 (선택)  │     │  ← "(선택)" 필수
│   └────────────────────┘     │
│                              │
│                              │
│        ┌──────────┐          │
│        │   시작   │          │  ← 처음부터 활성
│        └──────────┘          │
│                              │
│   과목 없이도 시작할 수 있어요 │  ← L3
│                              │
└──────────────────────────────┘
```

**과목 선택은 필수가 아니다.** 과목 없이 시작한 세션은 `subjectName = null`로 저장된다.

- **`+` 칩에 "(선택)"을 붙인다.** 없으면 과목을 만들어야 시작할 수 있다고 오해한다
- **시작 버튼은 처음부터 활성.** 비활성으로 두면 최악이다
- 첫 경험은 "안 끊고 이어간 게 11분"을 마주하는 것이다. **그 앞에 입력 단계를 세우지 않는다**

**과목이 1개 이상일 때** — 마지막에 쓴 과목을 자동 선택해둔다. 대개 같은 과목을 연달아 하므로 조작이 한 번 줄어든다.

### 2-B. RUNNING (진행 중)

```
┌──────────────────────────────┐
│                              │
│                              │
│           수학                │  ← L3. null이면 빈 줄
│                              │
│                              │
│        1:23:45               │  ← L1, 화면에서 가장 큼
│                              │
│                              │
│                              │
│        ┌──────────┐          │
│        │   종료   │          │
│        └──────────┘          │
│                              │
│                              │
└──────────────────────────────┘
```

**이 화면이 비어 있는 것은 의도다.**

집중도나 이탈 횟수를 실시간으로 띄우면 사용자가 그걸 보려고 폰을 켜고, 그게 이탈로 기록된다. 측정이 측정을 망친다.

**일시정지·휴식 버튼 없음.** 넣지 않기로 결정한 사항이다.

**과목이 없으면 그 줄을 비워둔다.** `(과목 없음)`이나 `미지정`으로 채우지 않는다. 선택 사항의 부재를 결함처럼 보이게 하면 안 된다.

**결정할 것 하나** — 세션 중 하단 탭을 숨길지. 숨기면 최소화 원칙에 더 맞지만, 기록을 보러 갈 수 없다. 숨기는 쪽을 권한다. 공부 중에 리포트를 볼 이유가 없다.

### 2-C. 과목 선택 시트 (`+` 칩 → 바텀시트)

전체 목록과 관리 기능을 겸한다. **독립 화면이 아니다.**

```
┌──────────────────────────────┐
│  ▁▁▁▁                        │  ← 드래그 핸들
│  과목 선택                    │  ← L2
│                              │
│  수학              12세션  ⋮  │
│  영어               8세션  ⋮  │
│  국어               5세션  ⋮  │
│  한국사             2세션  ⋮  │
│  수햑               1세션  ⋮  │  ← 오타. 여기서 처리
│                              │
│  ┌────────────────────────┐  │
│  │ + 새 과목 입력          │  │
│  └────────────────────────┘  │
└──────────────────────────────┘
```

**목록이 비어 있을 때**

```
┌──────────────────────────────┐
│  ▁▁▁▁                        │
│  과목 선택                    │
│                              │
│                              │
│   아직 추가한 과목이 없어요    │  ← L2
│                              │
│   과목을 나누면 나중에         │  ← L3
│   기록을 찾기 쉬워져요         │
│                              │
│                              │
│  ┌────────────────────────┐  │
│  │ + 새 과목 입력          │  │
│  └────────────────────────┘  │
└──────────────────────────────┘
```

설명을 **"기록을 찾기 쉬워져요"로 한정한다.** 과목의 역할은 세션 목록에서 자기 기록을 식별하는 것이다. "과목별 통계를 볼 수 있어요"라고 쓰면 만들지 않기로 한 기능을 약속하는 셈이다.

**⋮ 를 누르면**

```
┌──────────────┐
│ 이름 바꾸기   │
│ 칩에서 숨기기 │
└──────────────┘
```

**이름 바꾸기 다이얼로그**

```
┌──────────────────────────┐
│ 과목 이름 바꾸기          │
│  ┌────────────────────┐  │
│  │ 수학               │  │
│  └────────────────────┘  │
│                          │
│ "수햑"을 "수학"으로 바꾸면 │  ← 소급 경고 필수
│ 기존 1개 세션도 함께      │
│ 변경됩니다               │
│                          │
│      [취소]  [바꾸기]     │
└──────────────────────────┘
```

**디자인 주의점**

- **세션 수가 판단 근거다.** "수햑 1세션"을 보면 오타임을 즉시 안다. `12세션` 같은 카운트는 L3로 작게, 과목명보다 약하게
- 항목 정렬은 **세션 수 내림차순**. 오타나 안 쓰는 과목이 자연히 아래로 모인다
- **삭제 버튼을 두지 않는다.** "숨기기"만 제공한다. 삭제하면 그 세션의 과목값을 어떻게 할지 정해야 하는데, 어느 쪽도 좋은 답이 아니다
- 숨긴 과목은 시트에서는 계속 보이되 흐리게 표시하고 `[다시 표시]`로 되돌릴 수 있게 한다. 칩 목록에서만 빠진다
- 소급 경고를 생략하면 안 된다. 과거 데이터가 바뀌는 유일한 조작이다

**설정 탭에는 진입점을 두지 않는다.** 과목을 고치고 싶어지는 순간은 세션을 시작할 때이고, 그때 바로 손이 닿는 곳에 두는 것이 낫다.

## 3. 체감 입력 — 종료 직후, 주 1회만

```
┌──────────────────────────────┐
│                              │
│                              │
│   방금 세션에서               │  ← L3
│   몇 분 정도 집중한 것         │  ← L1
│   같나요?                     │
│                              │
│                              │
│        ┌─────────┐           │
│        │   90    │ 분         │  ← 숫자 입력 또는 스테퍼
│        └─────────┘           │
│                              │
│                              │
│        ┌──────────┐          │
│        │   확인   │          │
│        └──────────┘          │
│                              │
└──────────────────────────────┘
```

**실측값을 절대 미리 보여주지 않는다.** 이 화면의 전체 목적이 편향 없는 자기 예측을 받는 것이다. 뒤로 가기로 건너뛸 수 있게 하되 실측 화면을 먼저 노출하는 경로는 만들지 않는다.

질문은 **하나만**. 두 개를 물으면 마찰이 커진다.

## 4. 세션 리포트 — 종료할 때마다

위에서 아래로 이 순서를 지킨다.

```
┌──────────────────────────────┐
│ ⓪ 격차 (체감 입력한 날만)      │
│  ┌──────────────────────┐    │
│  │ 체감      100분       │    │
│  │ 실측  최대 68분       │    │
│  │       +47% 과대평가   │    │  ← 강조색
│  │                      │    │
│  │ 가장 길게 이어간 건    │    │
│  │        11분          │    │  ← L1, 이 화면 최대
│  └──────────────────────┘    │
├──────────────────────────────┤
│ ① 구조 헤드라인               │
│                              │
│   최장 34분    6조각으로 끊김  │  ← L1, 나란히
│   세션 58분 중 59%            │  ← L3
│   기록 47분                   │  ← L3
├──────────────────────────────┤
│ ② 타임라인 스트립             │
│  ▓▓▓░░▓▓▓▓▓▓░▓▓▓▓░░░▓▓▓▓    │  ← 가로 100%
│  19:00                20:38   │
├──────────────────────────────┤
│ ③ 총량                        │
│   순공 최대 1시간 28분         │  ← L2
│   착석 1시간 38분  딴짓 10분   │  ← L2
├──────────────────────────────┤
│ ④ 지표 카드                   │
│   ┌────────┐ ┌────────┐      │
│   │집중밀도 │ │세션길이 │      │
│   │  90%   │ │  98분  │      │
│   └────────┘ └────────┘      │
├──────────────────────────────┤
│ ⑤ 이탈 목록                   │
│   19:24  인스타그램      4분  │
│   19:51  화면 켜짐(앱없음) 20초│
│   20:12  유튜브         6분   │  ← 길게 눌러 재분류
├──────────────────────────────┤
│ ⑥ 미분류 앱 (최대 2개)         │
│   "카카오톡"은?               │
│   [딴짓]  [허용]              │
├──────────────────────────────┤
│ ⑦ 메타                        │
│   수학 · 19:00~20:38          │  ← L3
└──────────────────────────────┘
```

**디자인 주의점**

- **⓪과 ①이 무게중심이다.** ②~⑦은 스크롤해서 보는 영역
- ⓪은 주 1회만 나타나므로, 없을 때 ①이 자연스럽게 최상단이 되어야 한다
- ⑤ 이탈 목록의 각 항목은 **길게 눌러 즉시 `[허용]`으로 변경**할 수 있어야 한다. 자동 분류 정확도가 낮으므로 오분류 수정 경로가 짧아야 한다
- ⑥은 **세션당 최대 2개.** 상한이 없으면 리포트 하단이 설문지가 된다
- "화면 켜짐 (앱 없음)"은 잠금화면·알림 확인 구간이다. "알림을 봤습니다" 같은 추정 문구를 쓰지 않는다
- 권한 미허용 시 ②를 권한 유도 배너로 대체

### 타임라인 스트립 사양

가로 막대 하나. `Row` + `weight` 방식이므로 구간 비율대로 폭을 나눈다.

```
▓▓▓░░▓▓▓▓▓▓░▓▓▓▓░░░▓▓▓▓
└─────────────────────┘
   구간 합 = 세션 전체 길이 (빈틈 없음)
```

**구간이 세션 전체를 빈틈 없이 덮어야 한다.** 구멍이 있으면 나머지 구간이 늘어나 비율이 조용히 왜곡된다. 눈으로 잡을 수 없으니 데이터 쪽에서 보장한다.

사선 패턴, 앱 아이콘 오버레이, 구간 탭 상세는 넣지 않는다. 앱 정보는 ⑤에 이미 있다.

**과목 없는 세션의 목록 표기**

```
9/7  19:00      순공 최대 1h 28m    ← 과목 없으면 시각만
9/7  수학 19:00  순공 최대 1h 28m    ← 있으면 앞에 붙음
```

## 5. 기록 탭 — 가장 중요한 화면

세 섹션이 위에서 아래로 이어진다. 탭이 아니라 스크롤이다.

```
┌──────────────────────────────┐
│ 【1】 판정                     │
│                              │
│  🎯 지난주 목표 달성           │  ← 달성 시에만
│     이탈 4.4회 → 3.2회        │
│                              │
│  지난 4주보다                 │  ← L1
│  잘하고 있어요                │
│                              │
│  최장 47분 (평소 38분)        │  ← L3 근거
│  집중 밀도 78% (평소 71%)     │
│  순공 21h                     │
│                              │
│  ── 다음 목표 ──              │
│  세션당 이탈  4.4회 → 3.4회   │
│  지난 4주 평소값입니다         │  ← L3
├──────────────────────────────┤
│ 【2】 이번 주                  │
│                              │
│  ◀  9월 1일 ~ 9월 7일  ▶     │
│                              │
│  최장 47분  ↑ 지난주 38분     │  ← L1
│  세션당 이탈 4.2회 ↓ 5.1회    │  ← L1
│                              │
│  순공 21h 24m / 착석 27h 30m  │  ← L2, 병기 필수
│  딴짓 6h 06m (22%)            │  ← 절대시간 먼저
│  집중 밀도 78% ↑ 71%          │
│                              │
│  ▁▃▅▂▇▄▁                     │  ← 일별 막대 7개
│  월화수목금토일                │
│                              │
│  ── 앱 순위 ──                │
│  유튜브   12회   68분          │
│  인스타   9회    31분          │
│                              │
│  ── 요약 ──                   │
│  "이번 주 딴짓의 절반이        │  ← 문단 1개
│   야간 세션에서 나왔어요"      │
│                              │
│  ── 세션 목록 ──              │
│  9/7 수학 19:00  순공 1h 28m  │
│  ...                          │
├──────────────────────────────┤
│ 【3】 누적 (15세션부터)        │
│                              │
│  이번 달 순공 84h              │
│  전체 순공 210h               │
│                              │
│  집중 시간대                  │
│  ░░▒▓█▓▒░░                   │
│  6  10  14  18  22            │
│                              │
│  최장 기록 47분 (8/22)        │
│  인식 격차 +38→+31→+24→+19%   │
├──────────────────────────────┤
│   ⏱ 타이머   📊 기록   ⚙ 설정  │
└──────────────────────────────┘
```

**디자인 주의점**

- **판정 문구가 이 화면의 얼굴이다.** 가장 크게, 여백을 충분히
- **미달성은 표시하지 않는다.** 목표 배지는 달성했을 때만 나타난다
- 전주 데이터가 없으면 `↑ 지난주 38분` 비교값을 **감춘다** (표시하지 않음)
- 【1】은 기준선 미활성 시 `기준선 계산에 세션 N개가 더 필요합니다` 한 줄로 대체
- 【3】은 15세션 미만이면 **섹션 전체를 조용히 감춘다.** 안내 문구도 넣지 않는다
- 첫 주에만 【2】 최상단에 1주차 격차가 추가된다

```
시작할 때 적으신 하루      3시간
이번 주 실측 하루 평균  최대 1시간 42분
```

**빈 상태 처리**

| 조건 | 표시 |
|---|---|
| 전체 세션 0개 | 섹션 구조를 감추고 `세션을 마치면 여기에 기록이 쌓입니다` 한 줄 |
| 이번 주 0개, 과거 있음 | 【2】만 `이번 주 기록이 아직 없어요`. **주 선택 화살표는 유지** |
| 기준선 미활성 | 【1】만 안내 문구 |
| 15세션 미만 | 【3】 감춤 |

## 8. 다이얼로그 4종

세션 종료 후 리포트 진입 **전에** 뜬다.

```
① 화면 꺼짐 60분 초과
┌──────────────────────────┐
│ 23:14~00:51 동안 화면이   │
│ 꺼져 있었어요.            │
│ 이 시간은 어떻게 할까요?   │
│  [공부했어요] [자리 비웠어요]│
└──────────────────────────┘

② 세션 180분 초과
   종료를 잊었는지 확인

③ 미완료 세션 복구
   앱 강제 종료·재부팅 후
   [이어서 기록] [삭제]

④ 미분류 앱
   리포트 하단에 인라인 (다이얼로그 아님)
```

## 9. 화면 흐름

```
[최초 1회] 온보딩
      ↓
 ⏱ 타이머 ──── 📊 기록 ──── ⚙ 설정
    │  └→ 과목 시트           └→ 앱 분류
    │ 종료        │
    ↓            │
 다이얼로그        │
    ↓            │
 체감 입력 (주1회) │
    ↓            │
 세션 리포트 ◀────┘ (세션 목록 탭)
```

라우트 7개. 세션 진행은 타이머의 **상태**이고, 과목 관리는 타이머의 **바텀시트**다. 둘 다 독립 화면이 아니다.

## 10. 디자인 체크리스트

만든 화면을 이 목록으로 검사한다.

- [ ] 어느 화면에서든 가장 큰 숫자가 **최장 구간 또는 이탈 횟수**인가 (타이머 RUNNING의 경과 시간은 예외)
- [ ] 순공시간에 "최대"가 붙어 있는가
- [ ] 순공과 착석이 항상 나란히 있는가
- [ ] "0회", "0분", "0%"가 어디에도 없는가
- [ ] 판정·목표가 타이머 화면에 새어 나오지 않았는가
- [ ] 목표 미달성이 표시되지 않는가
- [ ] 전주 데이터가 없을 때 비교값이 감춰지는가
- [ ] 타임라인 스트립 구간의 합이 세션 전체를 덮는가
- [ ] 이탈 목록에서 앱 재분류가 두 번 이내의 조작으로 가능한가
- [ ] 세션 진행 화면에 경과 시간·과목·종료 버튼 외에 아무것도 없는가
- [ ] 과목 시트에 삭제 버튼이 없고 숨기기만 있는가
- [ ] 이름 바꾸기에 소급 경고가 붙어 있는가
- [ ] 과목 0개 상태에서 시작 버튼이 활성이고 `+` 칩에 `(선택)`이 붙어 있는가
- [ ] 과목이 없을 때 `(과목 없음)` 같은 표기 없이 자리가 생략되는가
